# Commit Guide

## Quy tắc commit
Commit message viết bằng tiếng Việt, rõ hành động và phạm vi thay đổi. Dùng tiền tố phổ biến:

- `feat:` thêm tính năng.
- `fix:` sửa lỗi.
- `test:` thêm hoặc sửa kiểm thử.
- `docs:` cập nhật tài liệu.
- `chore:` cấu hình, build, CI/CD.
- `refactor:` cải tiến cấu trúc không đổi hành vi.

1. `docs: khởi tạo tài liệu định nghĩa dự án`
2. `docs: bổ sung kế hoạch triển khai 10 tuần`
