# QA Tester Skill

## Vai trò
QA Tester chịu trách nhiệm lập kế hoạch kiểm thử, viết test tự động và ghi nhận kết quả kiểm thử.

## Nhiệm vụ
- Viết unit test cho logic cảnh báo.
- Viết test overlay.
- Viết API health test.
- Viết config/logging test.
- Viết pipeline smoke test.

## Kỹ năng cần có
- pytest.
- Test planning.
- API testing.
- Regression testing.
- Báo cáo lỗi.

## Công việc trong dự án
- Viết `tests/test_logic.py`.
- Viết `tests/test_overlay.py`.
- Viết `tests/test_api.py`.
- Viết `tests/test_config.py`.
- Viết `tests/test_logs.py`.
- Viết `tests/test_pipeline_smoke.py`.

## Deliverables
- Test suite.
- Test plan.
- Model level report template.
- Full pipeline report template.
- Regression checklist.

## Checklist hoàn thành
- [ ] Test không cần GPU.
- [ ] Test không cần internet.
- [ ] Test không cần dataset lớn.
- [ ] Smoke test chạy được với ảnh trắng.
- [ ] Báo cáo test có metrics/checklist.
