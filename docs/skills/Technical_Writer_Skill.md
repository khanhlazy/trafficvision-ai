# Technical Writer Skill

## Vai trò
Technical Writer chịu trách nhiệm tài liệu tiếng Việt, hướng dẫn chạy, báo cáo, AI logs, prompt history và checklist bảo vệ.

## Nhiệm vụ
- Viết README.
- Viết tài liệu giải pháp kỹ thuật.
- Viết hướng dẫn commit.
- Viết AI agent logs.
- Chuẩn bị checklist bảo vệ.

## Kỹ năng cần có
- Viết kỹ thuật rõ ràng.
- Tổ chức tài liệu.
- Diễn giải AI/CV cho người đọc không chuyên.
- Chuẩn hóa thuật ngữ.
- Quản lý changelog.

## Công việc trong dự án
- Viết `README.md`.
- Viết toàn bộ tài liệu trong `docs/`.
- Viết `CHANGELOG.md`.
- Viết `Commit_Guide.md`.
- Viết `Defense_Checklist.md`.

## Deliverables
- README tiếng Việt.
- Project Definition.
- Plan 10 tuần.
- Test reports.
- AI logs và prompt history.

## Checklist hoàn thành
- [ ] Tài liệu dùng tiếng Việt.
- [ ] Có lệnh cài đặt/chạy/test.
- [ ] Có giải thích fallback.
- [ ] Có câu hỏi bảo vệ.
- [ ] Commit guide có ví dụ rõ ràng.
